# Transmutation Convenient - 便捷转化

## 本Mod為《ProjectE》的附屬Mod，致力於提高其與其他Mod的可交互性、降低繁複操作

*目前僅支持 Forge + 1.20.1 的《Minecraft》版本*

### 必要的前置Mod，缺失可能導致遊戲無法啟動：
- 《Just Enough Items》
- 《ProjectE》

### 非必要的前置Mod，缺失可能導致部分內容缺失：
- 《Re:Avaritia》
- 《Colytra》
- 《Ice And Fire Community Edition》

---

### 用於解決的問題：

- 修復在《ProjectE》中， `原版鞘翅沒有 EMC 值` & `即使用指令手動添加 EMC 值，也無法添加預期的數值` & `成功使用指令添加 EMC 值後，耐久不為滿的鞘翅仍然沒有EMC值` 的問題；將鞘翅的 EMC 值添加為5000。

- 修復在《Re:Avaritia》中，使用 `終焉鍛造台` 合成出的物品，不會被自動添加 EMC 值的問題。

- 修復當《IceAndFire Community Edition》、《ProjectE》、《ProjectE Integration》同時裝載時，會使所有物品的 EMC 值都無法正確加載的問題。

- 解決《ProjectE》中的 `暗物質劍` `紅物質劍` `紅物質拳劍` 默認按 C 鍵觸發的群體傷害效果，在 `虐殺敵對生物` 狀態下，既不會傷害《IceAndFire Community Edition》中已被馴服的 `龍` ，也不會傷害尚未被馴服的 `龍`的問題。

- 修復《ProjectE》中的 `豐收女神戒指` & `大天使的懲戒` 沒有被註冊為《Curios API》中的 `戒指` 的問題；使其被安放再《Curios API》中的 `戒指` 欄位時，能夠觸發應有的功能。

### 添加的功能：

- 在已學習轉化配方並且擁有足量 EMC 的情況下，在《Minecraft》原版的： `工作台` ，以及《Re:Avaritia》的： `伏聆工作台` `煉獄工作台` `終末工作台` `終焉工作台` `終焉鍛造台` 中。使用《Just Enough Items》的一鍵填入材料的功能時，將會自動從你的個人 EMC 賬戶中購買材料來彌補不足的材料。

- 當背包中持有來自《ProjectE》的 `便攜式轉化桌` 時，將自動學習背包中的物品的轉化配方。

- 使《ProjectE》的 `修復護符` 可以修復《Colytra》中，將胸甲與鞘翅融合而成的胸甲上的鞘翅。

- 添加 `EMC管道` 方塊，可以按照**優先級**傳遞 EMC 。且支持通過連接到轉化桌方塊，來自動將 EMC 匯入擺放該方塊的玩家的個人 EMC 賬戶。

- 添加 `自動販賣機` 方塊，可以將導入的物品自動販賣為 EMC ，並匯入擺放該方塊的玩家的個人 EMC 賬戶。

- 添加 `黑洞之桶` 物品，擁有三個模式，分別可以用於吸引物品、吸引流體、投擲來自《Re:Avaritia》的 `終望珍珠` 。且擁有自身獨立的存儲空間，且可以儲存流體。使用對 `黑洞之桶` 對 `自動販賣機` 使用 `Shift + 鼠標右鍵` 將會一次性販賣全部內容物，包括內部流體。

- 為《IceAndFire Community Edition》中的 `龍息鍛爐` 添加配方映射器，使其製造的物品可以被《ProjectE》根據合成配方自動賦予 EMC 值

- 添加指令 `/sePE true` ，使用後將禁用《ProjectE》中的部分物品與裝備並改變部分物品的合成配方。使用 `/tcPE false` 指令，則可解除。針對認為過於強大的裝備會破壞遊戲平衡，同時又仍想使用《ProjectE》中的部分飾品的人設計。

- 使當玩家騎乘《IceAndFire Community Edition》中的 `龍` 時，在從 `龍` 身上脫離時，將獲得一次免疫摔落傷害的效果，並在觸發之後清除。

- 使得《ProjectE》中的 `禁止火把` 被註冊為《Curios API》中的 `護符`；使其被安放在《Curios API》中的 `護膚` 欄位時，能夠觸發被放置為方塊時除照明外的應有功能。

### 已發現並修復的問題:

- 修復為《Re:Avaritia》添加的為 `終焉鍛造台` 合成出的物品，被自動添加 EMC 值遠遠小於合成材料的 EMC 值總和的問題

- 修復指令 `/sePE true` &  `/tcPE false` 修改物品和合成配方的行為，不會導致其 EMC 值變化的問題

## 開發背景：
本人長期受《Re:Avaritia》過於繁複且多樣化的合成材料所困擾，因多次陷入 `從轉化桌中尋找對應材料 → 發現仍然需要其他材料 → 繼續尋找` 的怪圈，故以為《Just Enough Items》添加的自動從 EMC 賬戶中購買並填入功能為起點，經多次迭代，成為目前的該模組

**每一個功能都來自於作者本人，在遊玩時經歷的某個具體困擾**

這也是 `Transmutation Convenient` 這個名字的起源，希望能讓每一個玩家體會到本人渴望的**便利**
