# Transmutation Convenient - 便捷转化

## 本Mod為《ProjectE》的附屬Mod，致力於提高其與其他Mod的可交互性、降低繁複操作

*目前僅支持 Forge + 1.20.1 的《Minecraft》版本*

### 必要的前置Mod，缺失可能導致遊戲無法啟動：
- 《Just Enough Items》
- 《ProjectE》

### 非必要的前置Mod，缺失可能導致部分內容缺失：
- 《Re:Avaritia》
- 《Colytra》

---

### 用於解決的問題：

- 修復在《ProjectE》中， `原版鞘翅沒有EMC值` & `即使用指令手動添加EMC值，也無法添加預期的數值` & `成功使用指令添加EMC值後，耐久不為滿的鞘翅仍然沒有EMC值` 的問題；將鞘翅的EMC值添加為5000。

- 修復在《Re:Avaritia》中，使用 `終焉鍛造台` 合成出的物品，不會被自動添加EMC值的問題。

### 添加的功能：

- 在已學習轉化配方並且擁有足量 EMC 的情況下，在《Minecraft》原版的： `工作台` ，以及《Re:Avaritia》的 `伏聆工作台` `煉獄工作台` `終末工作台` `終焉工作台` `終焉鍛造台` 中。使用《Just Enough Items》的一鍵填入材料的功能時，將會自動從你的個人EMC賬戶中購買材料來彌補不足的材料。

- 使《ProjectE》的 `修復護符` 可以修復《Colytra》中，將胸甲與鞘翅融合而成的胸甲上的鞘翅。

- 添加 `EMC管道` 方塊，可以按照**優先級**傳遞EMC。且支持通過連接到轉化桌方塊，來自動將EMC匯入擺放該方塊的玩家的個人EMC賬戶。

- 添加 `自動販賣機` 方塊，可以將導入的物品自動販賣為EMC，並匯入擺放該方塊的玩家的個人EMC賬戶。

---

## 開發背景：
本人長期受《Re:Avaritia》過於繁複且多樣化的合成材料所困擾，因多次陷入 `從轉化桌中尋找對應材料 → 發現仍然需要其他材料 → 繼續尋找` 的怪圈，故以為《Just Enough Items》添加的自動從EMC賬戶中購買並填入功能為起點，經多次迭代，成為目前的該模組

**每一個功能都來自於作者本人，在遊玩時經歷的某個具體困擾**

這也是 `Transmutation Convenient` 這個名字的起源，希望能讓每一個玩家體會到本人渴望的**便利**
